# AGENTS.md

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `wozhendeshifwa/jifen-lingqu`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its role name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

single-context: one root `CONTEXT.md` glossary plus `docs/adr/`; no `CONTEXT-MAP.md`, no per-package glossaries. See `docs/agents/domain.md`.
